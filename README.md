# 🌱 Plant Disease Detection Using MobileNetV2

## 📌 Project Overview
A deep learning-based image classification project that detects plant diseases from leaf images using the MobileNetV2 architecture.

## 🎯 Objective
To identify plant diseases through leaf image classification and support early detection using deep learning.

## 🛠️ Technologies Used
- Python
- Deep Learning
- TensorFlow / Keras (if used)
- MobileNetV2
- Image Processing

## ⚙️ Methodology
1. Collect and prepare the plant leaf image dataset.
2. Preprocess images for model input.
3. Use MobileNetV2 with transfer learning.
4. Train and evaluate the classification model.
5. Predict the disease category from new leaf images.

## 🌿 Applications
- Smart agriculture
- Early plant disease identification
- Crop health monitoring

## 👩‍💻 Project Type
Deep Learning | Image Classification | Transfer Learning
